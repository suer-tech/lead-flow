# Lead Flow — отдельная мини-CRM

Автономный канбан для ведения лидов. Он не связан с основным сайтом проекта и использует собственную SQLite-базу `leads.db`.

## Запуск

Из корня репозитория:

```powershell
python -m uvicorn app:app --app-dir lead-crm --host 127.0.0.1 --port 8090 --reload
```

После запуска открыть <http://127.0.0.1:8090>.

Либо запустить файл `lead-crm/start.ps1` из PowerShell.

При первом запуске в канбан автоматически добавляются 17 уже обработанных лидов с hh.ru на стадии «Предложение отправлено».

## Возможности

- восемь стадий: Новый, Предложение отправлено, Есть интерес, Диагностика, КП, Переговоры, Успех, Отказ;
- перемещение карточек мышью между стадиями;
- карточка компании с контактами, вакансией, персональным предложением, заметками, бюджетом и следующим действием;
- поиск по компаниям и содержимому карточек;
- счётчики активных лидов, лидов в работе и суммы воронки;
- REST API для будущей автоматизации: `GET/POST /api/leads`, `PATCH/DELETE /api/leads/{id}`.
